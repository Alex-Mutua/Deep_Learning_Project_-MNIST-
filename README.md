# Deep Learning Project – MNIST

## Overview

This project trains a **Multi-Layer Perceptron (MLP)** to classify handwritten digits from the **MNIST dataset**.

The goal is to demonstrate how a neural network can learn to recognize image patterns and perform **multi-class classification** on handwritten digit images.

## Dataset

The **MNIST dataset** contains:

- 60,000 grayscale images  
- Image size: **28 × 28 pixels**  
- **10 classes** representing digits **0–9**

## Approach

The notebook implements a neural network model that:

- Processes flattened image inputs  
- Learns patterns using hidden layers  
- Predicts the correct digit class

## Tools Used

- Python  
- NumPy  
- Deep Learning techniques
